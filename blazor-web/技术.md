# Blazor Web 应用 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 框架 | Blazor Server / WASM | 两种托管 |
| 组件库 | MudBlazor / Fluent UI | 现成组件 |
| 数据 | EF Core | 数据访问 |
| 实时 | SignalR | 双向通信 |
| 发布 | 静态 / 容器 | 部署灵活 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **渲染模式**：Server 与 WASM 差异
- **组件模型**：参数与事件
- **状态管理**：跨组件共享
- **SignalR**：实时通信

## 学习路径

1. 先做一个 Blazor 页面
2. 再学组件与状态
3. 最后加数据与发布
