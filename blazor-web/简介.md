# Blazor Web 应用 · 简介

> 用 C# 写交互式 Web（Blazor）

## 能做什么

- 组件化 Web 界面
- C# 全栈开发
- 实时交互（Server）
- PWA 离线（WASM）
- 复用后端库

## 适合的项目

- **内部系统**：全栈 C#
- **后台管理**：组件化
- **小工具 Web**：快速开发

## 本机环境

- 本机状态：⚠️ 需补装 .NET SDK
- 工具链：需装 .NET SDK；Blazor Server / WASM、MudBlazor
- 注意：C# 全栈：前后端同一语言，适合 .NET 技术栈团队

## 快速开始

```bash
dotnet new blazorwasm -n Web
cd Web && dotnet run
dotnet publish -c Release
```
