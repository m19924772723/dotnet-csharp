# Blazor Web 应用 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 组件

- **组件化**：可复用 UI
- **参数与事件**：父子通信
- **布局**：共享布局

## 渲染

- **Server**：实时交互
- **WASM**：离线 PWA
- **混合**：按页面选择

## 状态

- **共享状态**：跨组件
- **本地存储**：持久化
- **实时更新**：SignalR

## 部署

- **静态托管**：WASM
- **容器**：Server
- **CI/CD**：自动发布

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
