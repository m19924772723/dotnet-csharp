# Office 与系统自动化（C#） · GitHub 精选项目

> 以下为该方向值得参考的开源项目，星标为 2026-10 前后近似值，请以仓库当前页面为准。
> 「可借鉴」一栏说明读源码或使用时最值得学习的地方。

| 项目 | 星标 | 亮点 | 可借鉴 |
|---|---|---|---|
| [dotnet/Open-XML-SDK](https://github.com/dotnet/Open-XML-SDK) | 4k | Office 文档 SDK | 无 Office 处理 |
| [ClosedXML/ClosedXML](https://github.com/ClosedXML/ClosedXML) | 3k | Excel 读写 | 简洁 API |
| [EPPlusSoftware/EPPlus](https://github.com/EPPlusSoftware/EPPlus) | 3k | Excel 库 | 功能全面 |

## 使用建议

1. **先跑通再读码**：把项目跑起来，用一遍再回头看实现
2. **带着问题读**：聚焦「它怎么解决某个难点」，而不是逐行通读
3. **小步借鉴**：先抄一个模块的思路，再考虑整体架构
4. **注意许可**：商用前确认开源协议（MIT / Apache-2.0 / AGPL 差异很大）
