# Office 与系统自动化（C#） · 简介

> 用 C# 做 Office 与系统自动化（OpenXML / COM）

## 能做什么

- Excel / Word 批量生成
- PPT 处理
- PDF 处理
- 系统自动化（COM）
- 报表自动生成

## 适合的项目

- **报表自动化**：批量出表
- **文档批处理**：模板产出
- **Windows 自动化**：系统集成

## 本机环境

- 本机状态：⚠️ 需补装 .NET SDK
- 工具链：需装 .NET SDK；OpenXML SDK、ClosedXML、NPOI
- 注意：OpenXML 无需安装 Office；COM 方式需本机有 Office

## 快速开始

```bash
dotnet new console -n OfficeJob
dotnet add package ClosedXML
dotnet run   # 生成 Excel
```
