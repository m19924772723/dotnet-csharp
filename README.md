# C# / .NET — 桌面与后端（需补装）

**定位**：Windows 桌面（WPF / WinForms）、ASP.NET 后端、控制台工具

**本机状态**：⚠️ 需补装 SDK

**工具链**：仅运行时 8.0.11 已装（ASP.NET Core / NETCore / WindowsDesktop）；无 SDK

**建议技术栈**：.NET 8 SDK、C#、ASP.NET Core、WPF

**注意**：装 .NET SDK 后即可开发；当前 `dotnet --version` 会直接报错
