# WPF / WinForms 桌面应用 · 简介

> 用 WPF / Avalonia 开发现代 Windows 桌面应用

## 能做什么

- 桌面界面与数据绑定
- MVVM 架构
- 图表与主题
- 打包安装包
- 跨平台（Avalonia）

## 适合的项目

- **Windows 客户端**：企业内部
- **管理工具**：表格与表单
- **上位机**：设备界面

## 本机环境

- 本机状态：⚠️ 需补装 .NET SDK
- 工具链：需装 .NET SDK；WPF（Windows）、Avalonia（跨平台）
- 注意：WPF 仅 Windows；要跨平台可选 Avalonia

## 快速开始

```bash
dotnet new wpf -n App
cd App && dotnet run
dotnet publish -c Release
```
