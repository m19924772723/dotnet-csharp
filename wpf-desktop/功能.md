# WPF / WinForms 桌面应用 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 界面

- **布局**：Grid / StackPanel
- **控件**：列表 / 表格 / 表单
- **主题**：Material 风格

## 架构

- **MVVM**：绑定与命令
- **依赖注入**：服务解耦
- **导航**：页面切换

## 组件

- **图表**：趋势与统计
- **数据网格**：可排序筛选
- **对话框**：交互

## 打包

- **安装包**：MSI / 单文件
- **图标与版本**：专业化
- **更新**：升级机制

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
