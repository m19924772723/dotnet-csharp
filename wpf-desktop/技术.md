# WPF / WinForms 桌面应用 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| UI | WPF / Avalonia | 桌面框架 |
| 架构 | MVVM | 分层 |
| 工具包 | CommunityToolkit.Mvvm | MVVM 基建 |
| 主题 | MaterialDesignInXAML | 现代外观 |
| 图表 | LiveCharts / OxyPlot | 数据可视 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **XAML**：声明式界面
- **数据绑定**：Binding 与命令
- **MVVM**：View / ViewModel / Model
- **打包**：安装包与单文件

## 学习路径

1. 先做一个窗口与控件
2. 再引入 MVVM 与绑定
3. 最后加图表与打包
