# 类库与 NuGet 包 · 简介

> 编写可复用的 .NET 类库并发布 NuGet 包

## 能做什么

- 类库封装与 API 设计
- 单元测试
- NuGet 打包发布
- 文档生成
- 多目标框架

## 适合的项目

- **团队通用库**：多项目复用
- **开源包**：对外发布
- **能力 SDK**：集成

## 本机环境

- 本机状态：⚠️ 需补装 .NET SDK
- 工具链：需装 .NET SDK；xUnit、Source Generators、NuGet
- 注意：多目标框架与语义化版本是库的基本素养

## 快速开始

```bash
dotnet new classlib -n MyLib
dotnet pack -c Release
dotnet nuget push bin/Release/*.nupkg
```
