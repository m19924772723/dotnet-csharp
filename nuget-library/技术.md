# 类库与 NuGet 包 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 语言 | C# / .NET Standard | 兼容多版本 |
| 测试 | xUnit / FluentAssertions | 单元测试 |
| 文档 | XML 注释 + DocFX | API 文档 |
| 发布 | NuGet | 包分发 |
| 生成 | Source Generators | 编译期增强 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **API 设计**：易用、稳定、可扩展
- **多目标框架**：兼容面
- **二进制兼容**：不破坏老用户
- **语义化版本**：版本约定

## 学习路径

1. 先封装一个小类库
2. 再写测试与文档
3. 最后发布 NuGet
