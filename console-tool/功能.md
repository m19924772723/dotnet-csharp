# C# 控制台工具与批处理 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## CLI

- **子命令**：功能分组
- **帮助信息**：自动生成
- **退出码**：可判断

## 文件

- **批量处理**：遍历与转换
- **文本处理**：查找替换
- **压缩**：归档

## 数据

- **导入导出**：CSV / Excel
- **数据库**：批量读写
- **报表**：统计输出

## 调度

- **定时执行**：计划任务
- **断点续跑**：可恢复
- **日志**：过程留痕

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
