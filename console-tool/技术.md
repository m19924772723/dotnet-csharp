# C# 控制台工具与批处理 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| CLI | System.CommandLine | 参数与子命令 |
| 数据 | Dapper | 轻量数据访问 |
| 日志 | Serilog | 结构化日志 |
| 输出 | Spectre.Console | 漂亮的终端 |
| 打包 | AOT 单文件 | 免装分发 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **参数解析**：命令与选项
- **异步 IO**：异步读写
- **AOT**：单文件免装运行
- **跨平台**：同一程序多系统

## 学习路径

1. 先写一个读参数的程序
2. 再抽成 CLI 工具
3. 最后 AOT 打包分发
