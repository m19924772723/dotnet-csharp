# C# 控制台工具与批处理 · 简介

> .NET 控制台工具与批处理程序

## 能做什么

- CLI 工具与子命令
- 批量文件处理
- 数据导入导出
- 定时批处理
- 跨平台分发

## 适合的项目

- **内部工具**：批处理
- **数据导出**：报表
- **运维脚本**：跨平台

## 本机环境

- 本机状态：⚠️ 需补装 .NET SDK
- 工具链：需装 .NET SDK；System.CommandLine、Serilog、Dapper
- 注意：⚠️ 缺 SDK，装好即可用；可 AOT 出单文件可执行

## 快速开始

```bash
dotnet new console -n Tool
cd Tool && dotnet run -- --help
dotnet publish -c Release -r win-x64 --self-contained
```
