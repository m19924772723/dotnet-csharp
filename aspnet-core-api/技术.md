# ASP.NET Core Web API · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 框架 | ASP.NET Core 8 | 跨平台高性能 |
| 数据 | EF Core / Dapper | ORM 双选 |
| 文档 | Swagger / OpenAPI | 接口文档 |
| 日志 | Serilog | 结构化日志 |
| 容器 | Docker | 部署一致 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **依赖注入**：内置 DI 容器
- **中间件管道**：请求处理链
- **EF Core**：Code First 与迁移
- **发布**：AOT 与容器化

## 学习路径

1. 先写一个 Minimal API
2. 再加 EF Core 与分层
3. 最后加鉴权与部署
