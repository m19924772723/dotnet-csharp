# ASP.NET Core Web API · 开发计划

> 原则：**每个阶段都产出可运行、可验证的东西**，先小步跑通再逐步加深。

## 阶段一 · 装 SDK 跑通

- **目标**：跑通
- **产出**：可访问的接口

- [ ] 装 .NET SDK
- [ ] 建 WebAPI 项目
- [ ] 本地运行

## 阶段二 · 数据

- **目标**：持久化
- **产出**：带数据库的服务

- [ ] EF Core 模型
- [ ] 迁移建库
- [ ] CRUD

## 阶段三 · 安全

- **目标**：可开放
- **产出**：带鉴权的接口

- [ ] JWT
- [ ] 授权策略
- [ ] 全局异常

## 阶段四 · 部署

- **目标**：可交付
- **产出**：上线的服务

- [ ] Docker 打包
- [ ] AOT 发布
- [ ] 健康检查

---

### 里程碑与验收

| 阶段 | 验收标准 |
|---|---|
| 阶段一 · 装 SDK 跑通 | 可访问的接口 |
| 阶段二 · 数据 | 带数据库的服务 |
| 阶段三 · 安全 | 带鉴权的接口 |
| 阶段四 · 部署 | 上线的服务 |

> 建议：每完成一个阶段就在本目录下建一个具体项目子目录，把成果固化下来。
