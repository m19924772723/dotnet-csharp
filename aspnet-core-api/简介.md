# ASP.NET Core Web API · 简介

> 用 ASP.NET Core 构建高性能 Web API

## 能做什么

- REST 接口与 Minimal API
- EF Core 数据访问
- 鉴权与授权
- 依赖注入
- 接口文档

## 适合的项目

- **业务后端**：企业系统
- **跨平台服务**：多系统
- **内部 API**：稳定可靠

## 本机环境

- 本机状态：⚠️ 需补装 .NET SDK
- 工具链：.NET 运行时 8.0.11（已装运行时，**无 SDK**）、需装 .NET SDK
- 注意：⚠️ 本机只有运行时、没有 SDK，当前无法编译，需先装 SDK

## 快速开始

```bash
dotnet new webapi -n Api
cd Api && dotnet run
# 打开 http://127.0.0.1:5000/swagger
```
