# ASP.NET Core Web API · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 接口

- **Minimal API**：轻量路由
- **控制器**：经典分层
- **参数校验**：DataAnnotations

## 数据

- **EF Core**：实体与迁移
- **仓储**：数据访问封装
- **事务**：一致性

## 安全

- **JWT 鉴权**：接口保护
- **授权策略**：细粒度
- **CORS**：跨域

## 部署

- **容器化**：Docker
- **AOT 发布**：启动快
- **健康检查**：探活

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
